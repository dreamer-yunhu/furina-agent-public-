# 芙芙 Agent · Codex 风格 UI Demo

这是一个独立、无依赖的静态原型，用于先体验布局，不会改动现有项目。

## 启动
1. 解压 ZIP。
2. 双击 `index.html`，使用 Chrome 或 Edge 打开。
3. 点击左侧「会话 / 任务 / 审计 / 设置」体验导航。
4. 在会话页点击「批准执行」或「拒绝」；处理后的审批卡片会折叠，点击摘要可展开。
5. 点击「详情面板」查看右侧任务详情。
6. 审计页可以展开线程、搜索记录、筛选待审批项，并展开单条记录详情。

## 限制
- 所有线程、任务、审批、工具执行记录均为演示数据。
- 发送任务不会调用后端；批准/拒绝只改变本地界面状态，不会执行工具。
- 这是用于评审布局的独立原型，不是对现有 F1 代码的集成补丁。
- 深色主题暂未实现，主题按钮会提示后续完善。

## 设计重点
- 左侧紧凑导航 + 最近会话
- 中央内容优先的对话区
- 会话内审批卡片与自动折叠
- 按线程分组的审批审计
- 按需展开的右侧任务详情面板
