| `apps/desktop/tests/smoke_timeout_scanner.py` | 新增 | 指南 §六 场景 |

### 5.2 核心流程

1. 查询：`PENDING` 且 `deadline_at <= now`，按 `deadline_at` 升序，`LIMIT N`
2. 逐条**独立会话/事务**校验：
   - approval 仍 `PENDING`
   - execution 存在且 `execution.task_id == approval.task_id`
   - Task/Execution 均为 `WAITING_APPROVAL`
   - Task 非终态
3. `transition_pair(WAITING_APPROVAL → SUSPENDED)`
4. 仅 `(APPLIED, APPLIED)` 时调用 `on_suspended`
5. 汇总 `ScanReport`（scanned / suspended / skipped 原因计数 / errors）

### 5.3 约束

- **不改 Schema、不加依赖、不绕过 T19**
- 单候选失败不影响整轮
- 回调异常只记录，不回滚已提交状态
- 不把 `SUSPENDED` 自动转成终态
- 不自动批准/拒绝/恢复
