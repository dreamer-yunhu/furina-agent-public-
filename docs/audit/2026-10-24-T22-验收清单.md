## 二、拒绝路径（状态必须不变）

| # | 验收条件 | 失败结果 |
|---|---|---|
| 5 | 同 Execution 仍有 `PENDING` 审批 | `PENDING_APPROVALS` |

| 7 | Task 处于终态 | `ILLEGAL_STATE` |
| 8 | Task/Execution 不在 `WAITING_APPROVAL` / `SUSPENDED` | `ILLEGAL_STATE` |
| 9 | 任一审批 `tool_execution_status != NOT_STARTED` | `ALREADY_EXECUTED` |
| 10 | DB 内 `tool_name` 为空、`args_hash` 非 64 hex、`args_json` 非法或重算哈希不符 | `ARGS_MISMATCH` |
| 11 | `old_hash` 与文件现状不符 | `OLD_HASH_MISMATCH` |
| 12 | `old_hash is None` 且目标文件已存在 | `OLD_HASH_MISMATCH` |
| 13 | 审批不存在 / 不属于给定 Task 或 Execution | `NOT_FOUND` / `SCOPE_MISMATCH` |
| 14 | 校验失败后 Task/Execution 状态、审批状态均不变 | 断言 |
