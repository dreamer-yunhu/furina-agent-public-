<h2 id="坑-1">坑 1：State 中的 messages 字段没有用 add_messages 规约器</h2>

### ❌ 错误现象

- 流式输出时拿不到打字机效果
- 多轮对话时消息相互覆盖，用户消息丢失

### 🔍 原因分析

默认情况下，状态更新是**覆盖**（overwrite）而非**追加**。节点返回 `{"messages": [新消息]}` 时，旧消息被直接替换。

### ✅ 正确写法

```python
from typing import Annotated, TypedDict
from langgraph.graph.message import add_messages

class State(TypedDict):
    # 必须用 Annotated 绑定 add_messages 规约器
    messages: Annotated[list, add_messages]
```

<h2 id="坑-2">坑 2：节点没有返回值（return）</h2>

### ❌ 错误现象

- `INVALID_GRAPH_NODE_RETURN_VALUE` 错误
- 图执行到该节点后卡住或崩溃

### 🔍 原因分析

LangGraph 的每个节点必须返回一个字典（或 `Command` 对象）作为状态更新。没有 `return` 默认返回 `None`，框架无法处理。

### ✅ 正确写法

```python
async def furina_chat_node(state: State):
    response = await model.ainvoke(state.messages)
    return {"messages": [response]}  # 必须返回字典
```

<h2 id="坑-3">坑 3：Pydantic State 用了方括号索引（state["messages"]）</h2>

### ❌ 错误现象

`TypeError: 'State' object is not subscriptable`

### 🔍 原因分析

如果用 Pydantic `BaseModel` 定义 State，它是一个对象，不是字典。只能用点号（`.`）访问属性，不能用方括号（`[]`）。

### ✅ 正确写法

```python
# ❌ 错误写法
response = await model.ainvoke(state["messages"])

# ✅ 正确写法
response = await model.ainvoke(state.messages)
```

<h2 id="坑-4">坑 4：异步节点（async def）用了同步调用（graph.stream）</h2>

### ❌ 错误现象

`TypeError: No synchronous function provided to "furina". Either initialize with a synchronous function or invoke via the async API`

### 🔍 原因分析

`async def` 定义的节点是协程，必须用异步 API（`astream` / `ainvoke`）执行。`graph.stream` 是同步入口，无法 `await` 协程。

### ✅ 正确写法

```python
# ❌ 错误：同步入口调用异步节点
for event in graph.stream({"messages": [...]}):
    ...

# ✅ 正确：异步入口调用异步节点
async for event in graph.astream({"messages": [...]}):
    ...
```

<h2 id="坑-5">坑 5：异步函数没有用 asyncio.run() 启动</h2>

### ❌ 错误现象

`RuntimeWarning: coroutine 'stream_graph_updates' was never awaited`

### 🔍 原因分析

`async def` 函数被调用时只是返回一个协程对象，不会自动执行。必须在事件循环中运行。

### ✅ 正确写法

```python
# ❌ 错误：直接调用
stream_graph_updates(user_input)

# ✅ 正确：用 asyncio.run() 启动
asyncio.run(stream_graph_updates(user_input))
```

<h2 id="坑-6">坑 6：stream_mode="messages" 的事件是元组，不是字典</h2>

### ❌ 错误现象

`AttributeError: 'tuple' object has no attribute 'values'`

### 🔍 原因分析

不同 `stream_mode` 下，event 的数据结构完全不同：

| stream_mode | event 类型 | event 结构 |
|---|---|---|
| `"updates"` | `dict` | `{"节点名": {"messages": [...]}}` |
| `"values"` | `dict` | `{"messages": [...], ...}`（完整状态） |
| `"messages"` | `tuple` | `(AIMessageChunk, metadata)` |

### ✅ 正确写法

```python
# 流式打字机效果 → stream_mode="messages"
async for event in graph.astream(..., stream_mode="messages"):
    chunk, metadata = event  # 元组解包
    if metadata.get("langgraph_node") == "furina":
        print(chunk.content, end="", flush=True)

# 只看节点完整输出 → stream_mode="updates"
async for event in graph.astream(..., stream_mode="updates"):
    for node_name, update in event.items():  # 字典
        if "messages" in update:
            print(update["messages"][-1].content)
```

<h2 id="坑-7">坑 7：把 AIMessage 对象又塞进 AIMessage() 构造器</h2>

### ❌ 错误现象

- `pydantic_core.ValidationError: Input should be a valid string`（19 个验证错误）
- 错误信息指向 `content` 字段类型不符

### 🔍 原因分析

`model.ainvoke()` 返回的已经是 `AIMessage` 对象。你把它当作 `content` 参数传入 `AIMessage()`，相当于：

```python
AIMessage(content=AIMessage(...))  # ❌ 把对象当字符串用
```

### ✅ 正确写法

```python
# ❌ 错误：二次包装
return {"messages": [AIMessage(response)]}

# ✅ 正确：直接使用返回值
response = await model.ainvoke(state.messages)
return {"messages": [response]}
```

<h2 id="坑-8">坑 8：图的入口输入格式不正确</h2>

### ❌ 错误现象

- `GraphInputException: Expected dict, got HumanMessage`
- `ValidationError: Field required [type=missing, ...]`

### 🔍 原因分析

`graph.stream()` / `graph.invoke()` 只接受一个字典，且字典的键必须与 State 中定义的字段完全匹配。

### ✅ 正确写法

```python
# ❌ 错误：直接传入消息对象
graph.stream(HumanMessage("你好"))

# ❌ 错误：缺少 State 中定义的必填字段
graph.stream({"messages": [...]})  # 如果 State 还有 user_id、conversation_id 等必填字段

# ✅ 正确：传入完整的状态字典
graph.stream({"messages": [("user", "你好")]})

# ✅ 或者使用 OpenAI 兼容格式
graph.stream({"messages": [{"role": "user", "content": "你好"}]})
```

<h2 id="坑-9">坑 9：API 基础 URL 写错了（博查搜索）</h2>

### ❌ 错误现象

搜索工具调用失败，请求超时或 404/401。

### 🔍 原因分析

代码中使用的 URL 和官方地址不一致：

| 对比项 | 错误地址 | 正确地址 |
|---|---|---|
| Web Search API | `https://api.bochaai.com/v1/web-search` | `https://api.bocha.cn/v1/web-search` |

### ✅ 正确写法

```python
# ❌ 错误
url = "https://api.bochaai.com/v1/web-search"

# ✅ 正确
url = "https://api.bocha.cn/v1/web-search"
```

<h2 id="最终完整代码">✅ 最终正确的完整代码结构</h2>

```python
import asyncio
from typing import Annotated, TypedDict
from langgraph.graph import StateGraph, END
from langgraph.graph.message import add_messages
from langchain_openai import ChatOpenAI
from langchain_core.messages import AIMessage

# 1. State 定义：关键：add_messages 规约器
class State(TypedDict):
    messages: Annotated[list, add_messages]

# 2. 节点定义：异步，用 state.messages 访问，返回字典
model = ChatOpenAI(model="deepseek-v4-flash", ...)

async def furina_chat_node(state: State):
    response = await model.ainvoke(state.messages)  # 直接返回 AIMessage
    return {"messages": [response]}  # 不要二次包装

# 3. 构建图
builder = StateGraph(State)
builder.add_node("furina", furina_chat_node)
builder.set_entry_point("furina")
builder.add_edge("furina", END)
graph = builder.compile()

# 4. 调用：异步入口 + 正确的 stream_mode
async def stream_graph_updates(user_input: str):
    async for event in graph.astream(
        {"messages": [{"role": "user", "content": user_input}]},
        stream_mode="messages"  # 流式打字机效果
    ):
        chunk, metadata = event  # tuple 解包
        if metadata.get("langgraph_node") == "furina":
            print(chunk.content, end="", flush=True)

# 5. 启动入口
if __name__ == "__main__":
    user_input = input("User: ")
    asyncio.run(stream_graph_updates(user_input))
```

<h2 id="核心总结">🎯 核心总结（记住这 5 条，避开 90% 的坑）</h2>

| # | 核心原则 |
|---|---|
| 1 | State 里的 `messages` 必须用 `Annotated[list, add_messages]` |
| 2 | 节点必须返回字典 `{"messages": [新消息]}`，`AIMessage` 直接放进去，不要二次包装 |
| 3 | Pydantic State 用点号（`.`）访问属性，不用方括号 |
| 4 | `async def` 节点必须配 `graph.astream()` + `asyncio.run()` |
| 5 | `stream_mode="messages"` 事件是元组，用 `(chunk, metadata)` 解包 |
