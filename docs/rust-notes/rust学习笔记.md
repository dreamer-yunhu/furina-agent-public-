## 一、Cargo 常用命令

| 命令 | 作用 |
|---|---|
| `cargo run` | 运行 Rust 项目 |
| `cargo build` | 编译项目 |
| `cargo check` | **只检查**能否编译，不生成可执行文件（速度快） |
| `cargo add <crate>` | 添加依赖 |
| `cargo new <name>` | 创建新项目 |
| `cargo init` | 把已有项目改为 Cargo 管理 |
| `cargo test` | 运行测试 |
| `rustc` | Rust 的底层编译器（Cargo 底层调用的就是它） |

## 二、变量与基础概念

- **不可变性**：Rust 变量默认不可变，需要改变时在变量名前加 `mut` 关键字。
- **常量**：用 `const` 关键字定义；命名约定为**全大写 + 下划线**分隔单词（如 `MAX_POINTS`）。
- **遮蔽（shadowing）**：用同名 `let` 声明新变量，把新值绑定到该名字上；在绑定期间访问该名字只会拿到**新值**，旧值被"遮蔽"。
  - 旧值**依然存在于内存**中，当遮蔽它的变量离开作用域后，旧值会"露出来"。
  - **遮蔽可以改变变量的类型**——这一点是遮蔽与 `mut` 最本质的区别：`mut` 只能改值，不能改类型；Rust 里一个变量一旦定下类型就无法修改。

```rust
fn main() {
    let x = 5;
    println!("The value of x is: {}", x);   // 5

    let x = x + 1;  // 遮蔽：创建全新的绑定，旧 x=5 仍占用内存直到作用域结束
    println!("The value of x is: {}", x);   // 6

    {
        let x = x * 2;                       // 内层遮蔽
        println!("The value of x is: {}", x); // 12
    }                                        // 内层 x 离开作用域，外层 x=6 "露出来"
    println!("The value of x is: {x}");     // 6（{x} 是 Rust 1.58+ 的捕获写法）
}
```

## 三、数据类型

Rust 是**静态类型**语言：编译器必须在编译期知道所有变量的类型。它可以通过赋的值**推断类型**，但建议在给变量赋值时就**明确声明类型**（更利于阅读和维护）。

每一个值都属于某种 `data type`，分两大类：

```
数据类型
├── 标量型（单个值）   → 整型 / 浮点型 / 布尔型 / 字符型
└── 复合型（多个值组合）→ 元组 / 数组
```

### 3.1 整型

- 分**有符号**（`i` 开头）与**无符号**（`u` 开头，无符号即"默认 ≥ 0"）。
- 可存储范围（`n` 为位数）：
  - 有符号：`-(2^(n-1)) ~ 2^(n-1) - 1`
  - 无符号：`0 ~ 2^n - 1`
- 例：`i8` 存 `-128 ~ 127`；`u8` 存 `0 ~ 255`。
- **整型溢出**：当变量存储的数字超过声明类型能容纳的最大值即触发。

### 3.2 浮点 / 布尔 / 字符

- **浮点型**：`f64` / `f32`（Rust 默认浮点类型是 `f64`）。
- **布尔型**：只有 `true` 和 `false`。
- **字符型**：`char` 占 **4 字节**，表示一个 **Unicode 标量值**。
  - 只要 Unicode 能编码的内容都可以作为 `char` 的合法值（如 `'😻'`）。
  - `char` 存的是自然语言的最小组成单元，也包括 emoji。

### 3.3 复合型 · 元组（tuple）

- 用圆括号 `()` 定义，**必须显式声明类型**，**长度固定**。
- **解构（destructuring）**：近似 Python 的解包操作。
- 用 `点号 . + 索引` 直接访问元素，第一个索引为 `0`。
- **单元（unit）**：不带任何值的元组，值和类型都写作 `()`，表示"空值 / 空的返回类型"。
  - 一个表达式如果没有返回其他任何值，会**隐式返回单元值**。

### 3.4 复合型 · 数组（array）

- 每个元素**类型必须相同**，**长度固定**。
- 值写在方括号 `[ ]` 内、逗号分隔。
- 数组在**栈（stack）**上分配一整块、大小已知且固定的内存。
- 语法：`let 数组: [类型; 长度] = [值...]`；访问用 `array[index]`。
- 简写 `[值; 长度]` 可创建全相同数据的数组（如 `[3; 4]` = `[3,3,3,3]`）。
- 标准库提供类似数组、但**可增长/缩短**的结构——**Vector**（见《常见数据集合》篇）。

```rust
fn main() {
    let f = 2.0;          // 默认 f64
    let fl: f32 = 1.0;    // 显式 f32

    let heart_eyed_cat = '😻'; // char 是最原始的字面类型之一
    println!("{}, {}, {}", f, fl, heart_eyed_cat);

    // 元组：类型不同没关系
    let tup: (i32, f64, char) = (1, 5.001, '你');

    // 数组：长度与元素类型固定
    let array: [i32; 4] = [1, 2, 34, 5];
    println!("{:?}", array);
    println!("{}", array[1]);

    let same = [3; 4];          // 简写：四个 3
    println!("{:?}", same);

    // let (x, y, z) = tup;     // 解构（近似 Python 解包）
    let test = tup.1;           // 点号 + 索引访问
    println!("{}, {}", tup.0, test);
    println!("{:?}", tup);

    let empty: () = ();         // 单元值：类型是 ()，值也是 ()
    println!("{:?}", empty);
}
```

## 四、函数

- 用 `fn` 关键字声明：`fn name() {}`，参数放圆括号内、函数体放花括号内。
- **参数是特殊变量**，属于函数签名的一部分，**必须声明类型**；多个参数用逗号分隔。
- Rust 严格区分**语句（Statements）**与**表达式（Expressions）**：
  - **语句**：执行一些操作但**不返回值**的指令（如 `let x = 3;`）。
  - **表达式**：计算并**产生一个值**（如 `x + 1`；语句末尾不带分号的代码块也可以是表达式）。

```rust
fn main() {
    // 代码块作为表达式：值为其最后一行（无分号）
    let y = {
        let x = 3;
        x + 1        // 没有分号 → 表达式，把 4 交给 y
    };
    println!("y = {y}");   // 4
}
```
