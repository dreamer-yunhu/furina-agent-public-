# 常见数据集合 —— 向量、哈希映射、字符串

> 由 `常见数据集合——向量，哈希映射，字符串.txt` 美化整理，代码为课堂片段示意（非单文件可直接编译）。
> **共同点**：三者都属于标准库集合，数据统一存放在**堆（heap）**上。
> **Vec 的铁律**：只能存储**同一种类型**的数据；想让向量装不同类型 → 用**枚举**（见第三节）。

## 一、动态数组 Vector（`Vec<T>`）

### 1.1 创建

```rust
let mut v1: Vec<i32> = Vec::new();   // 方式一：new() 关联函数
let v2 = vec![1, 2, 3, 4, 5];        // 方式二：vec! 宏（编译器根据初始值自动推断类型）
```

- `vec!` 是一个**宏**，基于初始值创建 vector 时编译器会自动推断类型。

### 1.2 增删

```rust
v1.push(4);      // push：尾部追加元素
// v1.pop();     // pop：移除并返回最后一个元素
```

### 1.3 读取：索引 与 get()

```rust
let third: &i32 = &v2[2];            // 方式一：索引（越界会 panic —— 让程序崩溃）
println!("The third element is {}", third);

let third: Option<&i32> = v2.get(2); // 方式二：get() 返回 Option<&T>
if let Some(third) = third {          // 越界不 panic，而是拿到 None
    println!("The third element is {}", third);
} else {
    println!("There is no third element");
}
```

**两种读取的差别**：索引越界直接 panic；`get()` 返回 `Option`，让调用方安全处理"不存在"。

### 1.4 借用规则红线

```rust
let mut vec = vec![1, 2, 3, 4];
{
    let first = &vec[0];             // 先拿到不可变引用
    println!("The first element is {}", first);
}                                    // 让不可变引用先结束
vec.push(5);                         // ✅ 引用失效后才能做可变修改
```

> ⚠️ **不可变引用有效期间，不能对可变 vector 做修改操作**（`push` 需要可变借用，与未失效的不可变借用冲突）。

### 1.5 遍历

```rust
for i in &v2 {                       // ✅ 只读遍历推荐：借用
    println!("The element is {}", i);
}
// for i in v2 { ... }               // ❌ 不加 & 会发生所有权转移
```

### 1.6 用枚举让 Vector 存不同类型

```rust
enum SpreadsheetCell {
    Int(i32),
    Float(f64),
    Text(String),
}

fn main() {
    let row = vec![
        SpreadsheetCell::Int(3),
        SpreadsheetCell::Text(String::from("blue")),
        SpreadsheetCell::Float(10.12),
    ];                                // 看似不同类型，本质装的都是 SpreadsheetCell
}
```

**生命周期**：当一个 vector 离开作用域时，它连**堆上对应的数据一起被释放**。

## 二、字符串（`String` 与 `&str`）

### 2.1 核心事实

- Rust 的核心语言里只有**一种**字符串类型：**字符串切片 `str`**，通常以被借用的形式出现：`&str`。
- `String` 是标准库提供的、可增长的 UTF-8 字符串（分配在堆上）。

### 2.2 创建

```rust
let mut s = String::new();            // new() 新建空字符串
let data = "initial contents";
let mut s = data.to_string();         // 以 &str 为基础建 String
// to_string() 可作用于任何实现了 Display Trait 的类型

let s = String::from("3");            // 从字面量直接建（只要是 UTF-8 编码都行）
```

### 2.3 更新

```rust
s.push_str(&str);                     // push_str：附加一个 &str（不夺走所有权）
s.push('\n');                         // push：追加单个字符

// + 拼接：s1 的所有权被移动（add 的函数签名是 self 按值 + &str 参数）
let s1 = String::from("Hello,");
let s2 = String::from("world!");
let s3 = s1 + &s2;                    // s1 被 move，之后不能再使用 s1

// format! 宏：用 {} 占位，返回新的 String，不夺取任一操作数所有权
let s1 = String::from("Hello,");
let s2 = String::from("world!");
let s4 = format!("{}{}", s1, s2);     // s1、s2 都还能继续用
```

> 级联多个字符串时 `+` 显得笨重（`s1 + &s2 + &s3`…），推荐 `format!`。

### 2.4 为什么不支持索引？

```rust
// let h = s1[0];  ❌ 会编译错误！
```

- 字符串按 **UTF-8 编码**存储，不同文字占用**字节数不同**（中文 3 字节、西里尔文 2 字节……），无法保证"第 n 个字节"正好落在字符边界上。
- Rust 字符串的**长度 = 存储占用的字节数**，而非字符个数。

### 2.5 允许切片（按字节）

```rust
let hello = "Здравствуйте";           // 西里尔文，每字符 2 字节
let s5 = &hello[0..4];
println!("{}", s5);                    // 取的是前 4 个字节 = 前 2 个字符
```

> ⚠️ 切片若切在字符中间会 panic。这里"长度"指**字节数**，不是字符数。

### 2.6 遍历字符串

```rust
// 方式一：chars() 按"字符"遍历
for c in "你好，世界".chars() {
    println!("{}", c);
}

// 方式二：bytes() 按"字节"遍历 → 输出一串数字（Unicode 编码值）
for n in "你好，世界".bytes() {
    println!("{}", n);
}
```

> 记住——**字符串远没有你想象的简单**。它是字节序列 + 编码语义的组合。

## 三、哈希映射 HashMap（需手动导入）

```rust
use std::collections::HashMap;
```

### 3.1 创建与增查

```rust
let mut dict = HashMap::new();                       // 数据存放在堆上
dict.insert(String::from("Blue"), 10);               // insert(键, 值)
dict.insert(String::from("Yellow"), 50);

// 约束：所有键必须同类型，所有值必须同类型

let team_name = String::from("Blue");
let score = dict.get(&team_name).copied().unwrap_or(0);
// get()        → Option<&V>，返回引用
// .copied()    → Option<V>（对实现 Copy 的值）
// .unwrap_or() → 键不存在时给出默认值
```

### 3.2 遍历

```rust
for i in &dict {                       // 整体遍历：每项是一个 (键, 值) 对
    println!("{:?}", i);
}
for (key, value) in &dict {            // 解构遍历
    println!("{key}");
    println!("{value}");
}
```

### 3.3 所有权

- 键值对插入后，**所有权归 HashMap 所有**。
- 键/值实现 **`Copy` Trait** 的类型（如整数）：从栈上复制一份。
- 未实现 `Copy` 的（如 `String`）：发生**所有权移动**——存进去的是一个"胖指针"，原变量不能再使用。

### 3.4 更新

```rust
// 方式一：覆盖 —— 对已存在的键插入新值
dict.insert(String::from("Blue"), 20);               // "Blue" → 10 变 20

// 方式二：只在键不存在时插入 —— entry()
dict.entry(String::from("Red")).or_insert(50);
// entry(key)：检查该键是否存在，返回一个 Entry 枚举
// .or_insert(value)：键不存在 → 插入；键存在 → 不做改动，返回该键对应值的可变引用
```
