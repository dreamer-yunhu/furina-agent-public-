# 枚举（enum）、Option 与 match

> 由 `枚举2.txt` 美化整理。本篇主线：枚举变体怎么带数据 → `Option<T>` → `match` 模式匹配 → `if let` / `let else`。

---

## 一、枚举：让一个类型表达"多种可能性"

### 1.1 变体可以携带数据

```rust
#[derive(Debug)]                       // 未实现 Display 的类型，打印需先 derive Debug
enum IpAddr {
    V4(u8, u8, u8, u8),                // 元组变体：括号里的数据就是变体携带的值
    V6(String),
}

fn route(ip: &IpAddr) { /* ... */ }

fn main() {
    let four = IpAddr::V4(127, 0, 0, 1);          // 像调用关联函数一样构造变体
    let six  = IpAddr::V6(String::from("::1"));
    route(&four);
    route(&six);
    println!("{:?}", four);
}
```

> **关键理解**：编译器会隐式为每个变体生成一个**同名的关联函数**（构造函数）。
> 这就是为什么"变体携带数据"写出来像在调用 `IpAddr::V4(...)`。

### 1.2 单元变体 / 元组变体

- **单元变体**：变体本身就是值（如 `UsState::Alabama`）。
- **元组变体**：`()` 里的值才是变体携带的数据（如 `Coin::Quarter(UsState)`）。

```rust
#[derive(Debug)]
enum UsState {
    Alabama,                 // 单元变体
    Alaska,
}

impl UsState {
    fn existed_in(&self, year: u16) -> bool {
        match self {
            UsState::Alaska  => year >= 1959,
            UsState::Alabama => year >= 1819,
        }
    }
}

enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter(UsState),        // 元组变体：携带一个 UsState
}
```

## 二、Option<T>：有值 / 无值

```rust
// 概念上是这样（不用真写，Option 已被预导入，直接可用）：
// enum Option<T> {
//     Some(T),   // 有值，里面装的是 T 类型数据
//     None,      // 没有值
// }
```

- `Option<T>` 中的 `T` 是**泛型参数**，可代表任意类型。
- 它**太常用已被预导入**，无需显式 `use`。
- 用途：显式表达"一个类型要么有值、要么没有值"，消灭空指针类错误。

> ⚠️ **`Option<T>` 和 `T` 是两个不同的类型**（一个是枚举、一个是普通类型），不能直接混用。
> 想拿到里面的 `T`，必须走 `match` / `if let` / `unwrap` 这类手段——这强制你处理"可能没值"的情况。

## 三、match 模式匹配

### 3.1 语义与穷尽性

- **match**：把一个值与一系列**模式**比较，执行**最先匹配**的模式所关联的表达式。
- **分支必须涵盖所有可能**（对枚举：每个变体都要写一个分支）——这叫穷尽性，编译器强制保证。

```rust
fn value_in_cents(coin: &Coin) -> u8 {
    match coin {
        Coin::Penny => {
            println!("Lucky penny!");
            1
        }
        Coin::Nickel => 5,
        Coin::Dime => 10,
        Coin::Quarter(state) => {
            println!("State quarter from {:?}!", state);
            25
        }
    }
}
```

### 3.2 绑定携带的值

```rust
fn plus_one(x: Option<i32>) -> Option<i32> {
    match x {
        None => None,
        Some(i) => Some(i + 1),   // 变量 i 绑定 x 携带的值：x = Some(5) 时，i 绑到 5
    }
}
```

### 3.3 通配模式：`other` 与 `_`

- 用途：只关心少部分可能，其余情况统一处理。
- 规则：最后一个分支必须**涵盖之前所有情况**（通配 / 全枚举）。
- **`_`**：任意匹配模式下都能用，**不会绑定**变量的值。
- **`other`**：会**绑定**变量的值，可在分支里使用。

```rust
let dice_roll = 9;
match dice_roll {
    3 => add_fancy_hat(),
    7 => remove_fancy_hat(),
    other => println!("{:?}", other),   // 兜底分支，能拿到具体值
}
```

## 四、if let：只关心一个模式

- 处理"**只匹配一个模式**、其余全部忽略"的简化写法。
- 语法：`if let 匹配模式 = 值 { 匹配成功执行的表达式 }`，可加 `else` 分支处理其他情况。

```rust
let config_max = Some(3u8);
if let Some(max) = config_max {
    println!("The maximum is configured to be {}", max);
    // 小贴士：对堆上的数据，非引用情况下会把所有权移交给绑定变量，表达式结束即被回收
} else {
    println!("error!!!");    // else 分支作用类似 _，但可用于返回默认值
}
```

### let else：把"成功值"提升到外层作用域

- 作用类似 `if let`，但行为相反：若模式**匹配成功**，把值**绑定到外层作用域**继续往下走；
  若**不匹配**，则走 `else` 分支（else 必须以 `return` / `break` / `panic!` 之类结束，因为否则没法继续执行）。

```rust
let Some(max) = config_max else {
    // 匹配失败时从这里返回/跳出，不允许"落空"继续往下执行
    return;
};
println!("max = {max}");   // 匹配成功时 max 已在外层可用
```

## 五、要点速记

| 语法 | 适用场景 | 备注 |
|---|---|---|
| `match` | 需要穷尽所有可能 / 多分支 | 分支必须覆盖全部可能，编译器强制 |
| `other` / `_` | 兜底分支 | `other` 绑定值；`_` 不绑定 |
| `if let` | 只关心一种模式 | 可带 `else` |
| `let else` | 想"只关心一种模式"且成功后值要在外层继续用 | else 分支必须中断控制流 |

> 下一篇衔接：`Option` 里的 `T`、`Vec<T>` 的 `T` 都是**泛型**；`#[derive(Debug)]`、`to_string()` 依赖**Trait**——见《结构体 / 泛型 / 生命周期 / Trait》篇。
